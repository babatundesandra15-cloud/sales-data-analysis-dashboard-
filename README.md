Sales Data Analysis Dashboard

Overview

This project focuses on analyzing sales data to identify trends and provide insights into sales performance, revenue, costs, profit, customers, and products.

Tools Used

* Microsoft Excel
* Power Query
* Pivot Tables
* Data Visualization

Data Preparation

The sales dataset was cleaned and prepared using Power Query. The process included checking for missing values, identifying duplicate records, standardizing data formats, and preparing the data for analysis.

Analysis

The project includes analysis of:

* Total revenue
* Cost of goods sold (COGS)
* Profit
* Customer activity
* Product performance
* Sales trends
* City-level performance

Dashboard

An interactive Excel dashboard was created to present key performance indicators and visualizations from the analysis.

Project Outcome

The project demonstrates the use of Excel and Power Query to clean, analyze, and visualize sales data and communicate useful business insights.
